# AI Project 4 - Image Text Recognition

## Project Description

This project is an Image Text Recognition system using Optical Character Recognition (OCR).

It extracts text from an image and displays the recognized text.

## Technologies Used

- Python
- OpenCV
- Pytesseract
- Tesseract OCR
- Pillow
- Streamlit
